# 原生 iPhone 核心功能实施任务

任务依据 [design.md](design.md) 与 `specs/` 下的八份功能规格。所有勾选表示实现及该项验收均已完成。涉及真实设备、模型和 iCloud 的项目缺少接入条件时保持未完成，不用模拟结果代替。

交付顺序：第 1—6 组完成原生记录；第 7—8 组完成真实 AI；第 9—11 组完成资料流转；第 12 组验证整体交付。依赖以各组说明为准，局部功能通过不代表整个变更完成。
