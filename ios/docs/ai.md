# AI 估算与资料发送

个人版不需要自建服务器。「我的 → AI 估算」在 iPhone 输入自己的千问 API Key；密钥只存本机不可同步的 Keychain，不进入 App 包、资料导出、iCloud 备份或普通日志。当前固定使用千问AI平台 HTTPS 端点和 `qwen3-omni-flash`。配置后仍须阅读界面中的发送范围、[千问隐私政策](https://terms.alicdn.com/legal-agreement/terms/common_product_agreement/20260423150805928/20260423150805928.html)及费用说明，明确授权才会发送照片和该餐备注。此前已实现的 `services/food-estimation/` 私有服务保留为可选适配器，个人版不需要部署。

自动估算开关与发送授权独立：仅已授权且开启自动时，成功保存的带照片新版本会排队一次；关闭自动后仍可手动识别。离线时任务保存在本机，恢复联网且 App 获得运行机会后重新核对记录、输入版本、删除状态和授权。没有密钥或未授权时，饮食、照片、人工热量和回顾仍正常可用，不使用演示结果填充真实热量。

千问直连不能获得私有服务的跨进程幂等保证。请求可能已发出后，超时、响应丢失或 App 被结束会显示结果未知，不自动重发；用户明确重试可能再次计费。本机默认每 UTC 日最多 50 次尝试，不能代替供应商账户的金额预算。请自行在千问账户设置金额上限。撤回授权阻止新发送并取消待处理任务，但不能保证撤回已送达千问的资料。

最多发送九张归一化 JPEG，每张不超过 2 MiB，总计不超过 18 MiB；备注最多 8000 字符。千问官方将 `qwen3-omni-flash` 列为不支持结构化输出的旧型号，因此 App 提示模型返回 JSON，但不会发送不兼容的结构化输出参数。客户端只接受成功结束且可解析的文本 JSON，并逐字段核验食物项、热量合计、范围和实际模型 ID。无法识别、非法数值或不完整输出不会进入当前统计，也不会自动调用第二次模型修复。

成功估算保留食物项、可选克数、热量、假设、待澄清问题、估算范围、供应商与模型标识。结果是模型估算，不是营养数据库核实；范围不是统计置信区间。人工修正始终创建新版本，原模型结果留作历史；旧任务不会覆盖更新的备注、照片、删除状态或人工热量。重新识别或删除恢复都需要重新核对资格。

正式联调需要你在 iPhone 自行配置密钥并明确指定允许送往千问的一张测试照片。仓库只记录脱敏的测试结论，不保存密钥、原图或私人身体资料。可选私有服务的部署、令牌和清理说明见 `services/food-estimation/README.md`。
