# 回顾口径

首页当天汇总、回顾逐日详情、图表和可编码的 `DayReview`／`ReviewRange` 都调用同一组纯函数，包含资料集修订号，防止各页面自行计算不同口径。

「已记录摄入」只加当前输入版本的有效人工／AI 热量。未知、过期及失败不按零值计入；界面同时给出待估算餐数。没有训练时训练净消耗的已知合计为零，并明确注明无训练记录；存在待估算训练或缺当日有效个人资料时，总消耗未知。

完整统计日需要：用户确认已记全、至少一餐、每餐和所有正式训练都有有效热量。确认不代替估算。只有完整统计日且总消耗已知，才显示「摄入减消耗」差值。修改记录事实会清除原／新受影响日期的确认；仅热量估算或人工修正不清除确认。

七天／三十天范围包含截至日期，并按连续日历日排列。平均摄入只用完整统计日，显示样本天数；没有样本显示未知。摄入柱实心表示完整、斜线表示未完整；消耗折线在未知日断开。横向图表每一天有独立触控目标，亦可从逐日数值表选择查看缺失原因。阶段按当日生效区间归属。

时间线按当地时分排序，稳定身份用于同时间的固定次序。日历、文字／餐次／标签搜索、照片筛选和训练历史都只读取正式且未删除记录，草稿及回收站不混入结果。无结果时明确显示空状态。
