# 我的与设置页

设置页与记录、回顾共用黑白灰、系统字体和纯色背景。首页是身体资料、AI 估算、数据管理三条整行导航，相邻行用细线分隔；普通字号下名称和状态分居左右，辅助字号下状态放在名称下面。

## 状态

- 身体资料按设备当地的今天寻找有效资料，显示「待填写／已填写」，不受记录页历史日期影响。加载期间显示「载入中」，失败显示「暂不可用」及重试操作。
- 原生 AI 状态由既有配置、政策可用性和当前政策授权计算：「未配置／待授权／已授权／暂不可用」。「已授权」只表示同意当前政策，不表示已连接网络或已验证 API Key。
- 网页 AI 明确标注「演示」，不发送照片、备注或真实模型请求。
- 数据管理不推断备份状态。原生回收站入口显示「空／N 项」，网页说明自动备份、导入恢复与回收站在 iPhone 使用。

## 子页

身体资料以单列字段呈现，单位紧邻数值；摄入目标单独成组，估算预览分两行。原生保留生效日期和回溯确认，说明与历史版本折叠。保存按钮及校验反馈位于底部，保存不会自动设置摄入目标。

原生 AI 按连接密钥、授权、自动估算排列。未配置时强调保存密钥；待授权时直接展示发送范围、供应商、政策和费用，并强调授权操作；已授权后政策仍可展开。自动开关即时保存。密钥仍由 Keychain 保存，不进入导出；保存新密钥时若政策读取失败，首页也会刷新已撤回的旧授权状态。

导出生成后强调「存储到文件」。导入保留选择、迁移确认、冲突预览及确认操作；反馈位于相应操作附近，恢复旧版本单独折叠并保留影响确认。恢复确认使用明确包含取消按钮的系统 alert，保证最大辅助字号下也能退出。回收站按名称、删除日期、恢复与永久删除排列，保留 30 天期限和永久删除确认。

网页复用样式限定在 `mine-home`、`mine-sheet` 内；原生复用 `MinePage`、`MineSection`、`MineFieldRow`、`MineNavigationRow`、`MineDisclosure` 与 `MineActionStyle`。本次备份恢复只增加本机可选运行状态；业务记录与资料包格式保持兼容。

## 回归入口

- 网页：`BASE_URL=http://127.0.0.1:8766 npm test`，专项脚本 `verify-mine.cjs` 覆盖日期状态、保存与取消、即时开关、导出失败重试、键盘和嵌套返回焦点，以及 320／393 px 浅深色与 200% 重排。
- 原生核心：`cd ios/BojiCore && swift test`，覆盖资料版本、授权、导出、导入冲突、回收站和保留期限。
- 原生应用：`MinePresentationTests` 使用隔离目录、内存凭据与模拟服务验证状态；`WorkspacePortabilityTests` 覆盖导入刷新与恢复。
- 原生界面：`MineSettingsTests`、`ProfileTests` 和相关 `LaunchTests`、`ReviewAITests`、`ExportPhotoTests` 验证小屏、最大辅助字号、保存返回、系统文件选择器及原有记录／回顾流程。

本轮自动化检查使用浏览器与 iPhone 模拟器；真机 VoiceOver 朗读、系统文件提供者的云端上传状态仍需在设备上检查。

## iCloud 备份

数据管理顶部的 iCloud 备份入口按本机设置显示未设置、待启用、已开启或已停止。详情使用局部单列布局，不改变其他设置页：17pt 半粗体状态标题，下方紧凑组合最近完整备份时间与上传状态；时间按设备当地时区显示为 `yyyy/MM/dd HH:mm`。主要操作下只有一条分隔线，之后是备份位置与默认收起的备份说明。边距 16pt、分组间距 24pt、组内间距 6—8pt；长目录名换行，辅助字号改为上下排列并可滚动。

未设置时只显示「尚未开启备份」、备份范围和「选择目录并开启」，没有空目录、时间、上传状态或更多菜单。旧授权待启用时以「启用自动备份」为主按钮；已开启、已停止均以「立即备份」为主按钮。更换目录、停止自动备份及适用的启用／手动操作放在右上角「更多」。尚无成功写入时仅显示一次「尚无备份」。

新内容提示与失败原因就近显示在主按钮旁，失败仍保留最近成功备份信息。只有用户主动操作显示按钮进行中并防止重复提交，前台例行检查不改变按钮外观；进行中仍可通过菜单停止自动备份和使用系统返回。App 只保留简短备份说明；Mac 文件结构与校验方法放在 `import-and-backup.md`，不再提供单独的 App 入口。备份行为、格式和真机验收边界保持不变。

「更多」使用系统 popover 承载菜单，菜单行明确设置至少 44pt，并跟随辅助字号增高。iOS 26 默认导航背景会压缩自定义控件的有效点击范围，因此该入口使用独立的 44pt 控件并隐藏共享背景；系统返回导航保留。打开目录选择器前先关闭菜单，取消不会修改授权或启停状态。
