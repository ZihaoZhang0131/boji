# 个人资料、阶段和计算

「我的 → 个人资料」填写公式性别参数、整数年龄（18—59）、身高（100—230 cm）、体重（30—250 kg）和日常活动系数。每天摄入目标可留空，填写时须为 1—10000 kcal；它与静息估算、日常消耗是不同字段。未填资料不会阻止记录饮食或训练。

每次保存新增生效版本，默认今天生效；同日以最后一次明确保存为准。选过去日期时先显示影响区间并确认，只改变该区间的日常基线。第一份资料之前保持缺资料，历史训练始终保留原体重和算法快照。

「我的 → 阶段目标」支持缓慢减脂、稳步增肌和保持状态，第一次不预选。切换结束旧阶段，新阶段开始日包含、结束日不包含；同日切换保留零天旧阶段，最终阶段拥有当天。只修改备注不增加阶段，不根据阶段自动设定摄入量。

静息估算：10×体重 kg＋6.25×身高 cm－5×年龄＋男性公式 5／女性公式 -161，先四舍五入到整数，再乘日常活动系数得到基线并四舍五入。日常活动不含已经记录的训练。

力量训练净消耗：(MET－1)×3.5×体重 kg÷200×分钟。常规力量、深蹲／硬拉为主、高强度力量使用 3.5、5、6。整次训练只计算一次；缺参数为未知，不填零。所有结果是估算，公式输出与用户自定目标分别显示。
